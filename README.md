# 海大课程表

> 自用课表工具：从教务系统导入课表，导出到手机系统日历。
> 单文件 HTML，无框架、无构建、无外部请求，数据只存本地。

## 功能

- **周课表**：5 天 / 7 天两种视图，左右滑动翻周，支持假期、调休、调课
- **导入**：教务页面书签脚本一键抓课表，或粘贴 JSON / 文件导入
- **导出日历**：生成 ICS，带时区、提醒（5/10/15/20 分钟可选）和可选「闹钟风格」事件
- **备份**：localStorage 持久化，支持导出 / 恢复 JSON
- **外观**：浅色 / 深色主题 × 六套皮肤
- **分享**：Canvas 生成本周课表图片

## 使用

### 电脑

双击 `海大课程表.html` 即可。也可以起本地静态服务：

```bash
python -m http.server 8642 --directory .
```

然后打开 `http://localhost:8642/海大课程表.html`。

### 手机

把 `海大课程表.html` 传到手机，用浏览器打开（实测 iQOO + Edge 可用）。
可以配合 `桌面图标\` 里的图标添加到主屏幕。

### 从教务导入

1. 浏览器登录教务系统，打开课表页面
2. 新建一个书签，地址填 `教务课表导出书签.js` 的全部内容
3. 在课表页面点这个书签，脚本会读取页面已有的课表数据，生成 JSON 并复制到剪贴板
4. 回到应用，点「导入」→ 粘贴 JSON

也可以点「文件」导入之前导出的 JSON，或手动添加课程。

## 数据存在哪

- `localStorage` 的 `shmtuSchedule.v1`（课表）和 `shmtuSchedule.settings`（设置）
- 不联网、不上传、没有账号
- 建议定期导出 JSON 备份；应用在课程较多且长期没备份时会提醒

## 目录

```
.
├─ 海大课程表.html          应用本体（单文件）
├─ 教务课表导出书签.js       教务页面抓取脚本
├─ 示例课表.json            示例数据（假课程，用于试导入）
├─ 桌面图标\                添加到手机主屏幕用的图标
└─ README.md
```

## 说明

- 本项目按上海海事大学金智 EAMS 教务系统页面结构编写，其他学校需要改书签脚本里的解析逻辑
- 教务数据属于学校与个人，仓库不带真实课表；`示例课表.json` 是虚构数据
